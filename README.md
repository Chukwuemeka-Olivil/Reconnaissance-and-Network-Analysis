# Reconnaissance and Network Analysis

Practical cybersecurity labs completed using Kali Linux, covering network reconnaissance, information gathering, network scanning, and packet analysis.

## Environment

- Kali Linux
- Linux command line
- Virtualized lab environment

## Tools and Technologies

- Ping
- Nslookup
- Dig
- WHOIS
- theHarvester
- Sublist3r
- Bash scripting
- Nmap
- Wireshark

## Skills Demonstrated

- Network reconnaissance
- Information gathering
- DNS analysis
- WHOIS analysis
- Subdomain enumeration
- Passive intelligence gathering
- Network scanning
- Packet capture
- Packet analysis
- Network traffic analysis
- Bash scripting and automation
